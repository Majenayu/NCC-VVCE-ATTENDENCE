# Security policy

This application handles attendance records, uploaded images, and account
credentials. Do not use production or personal data when reproducing an issue.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting flow when available, or contact the maintainer
privately through GitHub with the affected path, redacted reproduction steps,
impact, and mitigation. Never include passwords, tokens, images, or student
records.
